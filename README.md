The Leonida Trophy Fieldbook — the best guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade, a checklist saved in the browser, export and import, filters by kind and grade, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, the missable trophies flagged, and a guide to each trophy in your own words that cites its sources.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

To build the submission dossier instead:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
